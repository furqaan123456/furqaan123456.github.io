Real-Time CDC and Batch Platform for Retail Analytics

Retail analytics · Change data capture plus scheduled batch loads
  • Combined REST API, CSV and real-time PostgreSQL CDC data into one retail data warehouse using Debezium, Kafka and Airflow.
  • Designed a layered warehouse (Raw, Staging, Intermediate, Marts) in PostgreSQL and dbt, with incremental transformations.
  • Added automated data quality checks with Great Expectations and 24 dbt tests.
  • Orchestrated batch and streaming ingestion in Airflow, with SLA monitoring, failure alerts and recovery workflows.
  • Generated dbt lineage docs and wrote source-to-warehouse reconciliation tests for row counts and revenue accuracy.
  • Packaged everything with Docker Compose so the platform runs locally from one command.

Real-Time Ride-Hailing Pipeline

Mobility · Kafka, Flink and ClickHouse streaming to live dashboards
  • Wrote a Python event simulator that publishes ride, driver-location and trip events to Kafka, with Avro schemas managed in Schema Registry.
  • Built Flink SQL jobs for real-time processing, including windowed aggregations on trip and demand metrics.
  • Loaded processed streams into ClickHouse for low-latency analytical queries, and used Redis as a fast layer for live state.
  • Created Grafana dashboards to monitor key ride-hailing metrics in real time.
  • Containerized the full stack with Docker Compose and documented the architecture and setup in the repository.

Databricks Lakehouse for FMCG

Consumer goods · Medallion architecture on Delta Lake
  • Ingested raw sales, customer and product data from Amazon S3 into Databricks using a bronze, silver and gold medallion design.
  • Cleaned and standardized data in PySpark and Spark SQL notebooks, handling duplicates, nulls and data-type inconsistencies.
  • Stored every layer as Delta tables and used incremental processing so unchanged data is not reprocessed.
  • Modeled fact and dimension tables in the gold layer for sales and product performance reporting.
  • Version-controlled all notebooks in GitHub.
